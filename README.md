# Extraction Image
Ce projet cherche à créer un logiciel permettant d'expliquer les différente étape des algorithmes de detections de bordure.

 Algorithme implémenter à ce moment:
    Canny edge detection
    Deriche Filter
    SUSAN Method

# Requirement
Les librairie python suivante sont nécessaire:
   - numpy
   - matplotlib
   - PyQt5
   - qt_material

# Usage
Lancer le fichier [MainGUI.py](MainGUI.py) pour lancer le logiciel
Le code de chacun des algorithmes se trouve dans le fichier [function.py](function.py)
